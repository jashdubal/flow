ƒ FLOW

A minimalist focus timer for macOS. Lives in the menu bar, counts down flow and break phases, and records every focused minute into a heatmap. Native, no account, no network.

DOWNLOAD FOR MAC

UNIVERSAL · macOS 13+ · FREE

  1. Open the DMG and drag Flow to Applications.
  2. The build is ad-hoc signed, so the first launch is blocked. Right-click Flow → Open → Open. Once only.
  3. Left-click the menu bar mark to show the timer, right-click to start or pause, Control-click for the menu.
